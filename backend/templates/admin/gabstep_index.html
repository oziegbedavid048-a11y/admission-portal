Working the pipeline.
  1. Applications is the main screen: verify documents, move a file to the next stage, grant admission, confirm a visa. Add an issued letter on an application and the applicant sees it on their dashboard straight away.
  2. Partners & sales is where agent and sales manager requests are approved: ad funding, agent payouts and sales manager payouts.
  3. Payments confirms an application fee that arrived off platform, which also pays the agent their commission.
  4. Add course is the whole catalogue in one screen. Paste a school's course list, check what was read, set the application fee, and the country, the school and every course are created in the right place. Links at the foot of that screen reach the existing rows if one needs correcting.
Select rows and choose an action from the dropdown to handle several at once. Everything that changes what an applicant can see also writes them a notification.
