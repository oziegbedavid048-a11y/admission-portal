Working the pipeline.
  1. Applications is the main screen. Each action does one job, in this order: verify personal details, academic details, uploaded documents and the application fee (all four makes the file Verified); send to institution; grant admission or decline; transfer to the Visa Support desk. Add an issued letter on an application and the applicant sees it on their dashboard straight away.
  2. Visa Support Queue lists admitted students only: start visa processing, then confirm the visa, which credits the agent's visa commission.
  3. Documents and Correction requests are for single items: verify or reject one upload, approve or decline one correction.
  4. Support messages (under Accounts) lists what people sent from the Support page. Open one, type in Reply and save: the answer is emailed to them and shown on their Support page.
  5. Partners & sales is where agent and sales manager requests are approved: ad funding, agent payouts and sales manager payouts.
  6. Payments confirms an application fee that arrived off platform, which also pays the agent their commission.
  7. Add course is the whole catalogue in one screen. Paste a school's course list, check what was read, set the application fee, and the country, the school and every course are created in the right place. Links at the foot of that screen reach the existing rows if one needs correcting.
Select rows and choose an action from the dropdown to handle several at once. Everything that changes what an applicant can see also writes them a notification.
